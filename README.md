# prunehex

Prune lightweight hex statistics from stdin samples.

**Site:** https://theworker02.github.io/prunehex/

## Install / run

```bash
git clone https://github.com/theworker02/prunehex.git
cd prunehex
node src/cli.js
node --test
```
